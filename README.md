# Entwickelter-Prototyp-einer-Tagesplaner-App-im-Kontext-von-WfbM
Dieses Repository enthält den entwickelten Prototyp einer webbasierten Tagesplaner-App im Kontext von Werkstätten für behinderte Menschen (WfbM).  Die Anwendung unterstützt Nutzerinnen und Nutzer durch eine visuelle Tagesstruktur, schrittweise Aufgabenführung, Erinnerungen, Planänderungen und einen einfachen Hilfezugang.
